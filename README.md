# Personal Library Manager

A web application for organising a personal book collection,
searching for books, tracking reading progress, and managing
a wishlist.

## Planned Technology Stack

- Python
- Flask
- MySQL
- HTML, CSS, and JavaScript

## Planned Features

- Add, view, edit, and delete books
- Look up book metadata using an ISBN or title
- Enter Goodreads ratings manually
- Search and filter the collection
- Track reading status and wishlist items
- Store collection data in MySQL

## Project Status

Currently in initial development.

## Learning Goals

- Build a full-stack web application
- Practise SQL and database design
- Learn HTTP requests and Flask routes
- Use Git to track changes
- Test and debug the application
